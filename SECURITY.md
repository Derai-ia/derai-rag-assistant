# Security policy

This repository is a demonstration, not a production security boundary. Do not add real personal data, API keys, access tokens, or customer documents. Use environment variables or a secret manager for local provider credentials; never commit `.env` files.

If you find a vulnerability, report it privately through the repository host's security reporting feature when available. Include affected versions, reproduction steps, impact, and a suggested mitigation. Avoid opening a public issue for an unpatched vulnerability.
