# Caso de soporte 02: etiqueta duplicada
La empresa ficticia Taller Lumbre reportó dos etiquetas para un mismo paquete. El equipo anuló la etiqueta antigua en el TMS, verificó el identificador activo con almacén y notificó al cliente. Resolución: un único envío válido.
