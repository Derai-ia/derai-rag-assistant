# Caso de soporte 04: mercancía dañada
El cliente ficticio Mercado Nival recibió una caja húmeda. Se abrió expediente, se solicitaron fotografías y se aisló el lote restante. Calidad determinó daño durante transporte y se acordó reposición. Resolución: reposición programada y transportista notificado.
