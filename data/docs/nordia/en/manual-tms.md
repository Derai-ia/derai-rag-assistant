# Internal TMS manual
## Create a shipment
In the Shipments menu, select New, enter origin, destination, packages, and delivery window; validate the address and select Save. The system generates an ND identifier and requests confirmation from the carrier.
## Tracking
Search by identifier or customer reference. The statuses are Prepared, Picked Up, In Transit, Out for Delivery, and Delivered. If no events arrive for six hours, check the carrier connection and open an incident.
